# 💧 Créer une source d’eau infinie en Skyblock

Une source d'eau infinie permet de remplir autant de seaux que nécessaire pour les cultures, générateurs et chutes de sécurité. En Skyblock, elle doit être construite dès que deux sources sont disponibles.

Le bassin classique mesure deux blocs sur deux. En plaçant les deux sources dans des coins opposés, chaque case devient une source renouvelable que le joueur peut reprendre sans vider l'ensemble.

## 🧰 Matériel nécessaire

- Deux sources d’eau
- Un seau
- Des blocs pleins
- Une plateforme sous le bassin
- Des dalles pour les bords
- Un toit si le biome gèle
- Un coffre pour conserver un seau de secours

## 🛠️ Construire le bassin deux par deux

1. Agrandissez une plateforme pleine loin du bord de l'île.
2. Creusez ou entourez un carré intérieur de deux blocs sur deux.
3. Vérifiez qu'un second sol protège le dessous du bassin.
4. Versez la première source dans un coin.
5. Versez la seconde dans le coin diagonal opposé.
6. Attendez que les quatre cases deviennent calmes et sans courant.
7. Prélevez un seau dans un coin, puis vérifiez que la source se reforme.

## ⚙️ Protéger la réserve principale

Gardez toujours un seau rempli dans un coffre séparé. Il permettra de réparer le bassin si un joueur retire plusieurs sources ou si un mécanisme l'endommage.

Dans un biome froid, couvrez l'eau avec un toit ou des dalles adaptées pour éviter le gel. Éloignez aussi les courants de la zone de stockage.

## ⚠️ Problèmes courants

### Le bassin crée encore des courants

Les deux sources ne sont pas placées en diagonale ou une case manque de support. Videz puis recommencez dans un carré complet.

### Prendre un seau vide le bassin

Prélevez une source dans le modèle deux par deux et attendez sa régénération avant le seau suivant.

### L'eau gèle

Ajoutez un toit, augmentez la lumière locale ou déplacez la réserve dans une zone protégée.

## ✅ À retenir

Deux sources placées en diagonale dans un bassin deux par deux créent une réserve renouvelable. Construisez-la sur un double sol et gardez toujours un seau plein hors du mécanisme.
